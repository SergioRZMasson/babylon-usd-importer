# Third-party software

This project builds and distributes code from:

- [Pixar OpenUSD](https://github.com/PixarAnimationStudios/OpenUSD), modified and distributed
  under its Apache-2.0 license.
- [oneTBB](https://github.com/oneapi-src/oneTBB), distributed under Apache-2.0.
- [zlib](https://github.com/madler/zlib), distributed under the zlib license.
- [Babylon.js](https://github.com/BabylonJS/Babylon.js), consumed as an npm peer/development
  dependency under Apache-2.0.

The corresponding source packages and copyright files are installed by vcpkg or npm during
the build.
